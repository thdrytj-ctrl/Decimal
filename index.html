선생님으로 시작하기

우리 반 학생들의 풀이 기록, 오개념 분포, 게임 랭킹을 확인하고 PIN을 초기화합니다.

📦 예전 기록(localStorage) → Firestore 이전

예전 버전은 기록이 각 컴퓨터(브라우저)에 따로 저장되어 있었어요. 학생들이 쓰던 컴퓨터마다 한 번씩 이 버튼을 눌러 주면 모든 기록이 한곳(Firestore)에 모입니다. 같은 기록을 여러 번 이전해도 중복되지 않습니다.

학습 기록과 계정(이름·PIN)은 Firebase Firestore(클라우드)에 저장되어 어느 기기에서 접속해도 같은 데이터가 실시간으로 함께 보입니다. '이어서 학습하기'용 최근 이름만 이 브라우저에 남습니다. 소수 세 자리 이상의 수는 입력할 수 없도록 제한되어 있습니다.

빈자리에는 0이 숨어 있다는 것도 기억해 볼까요?

첫째 수 0 둘째 수 0 모눈 판 1장

길쭉한 판 전체 = 1, 한 칸 = 0.1 이에요. 0.1이 10개 모이면 1이 된다는 것을 손으로 확인해 보세요.

첫째 수 0 둘째 수 0 모눈 판 1장

한 판 전체 = 1, 한 줄 = 0.1, 한 칸 = 0.01 이에요. 합이 1보다 커지면 모눈 추가 버튼으로 판을 늘려서 칠해 보세요.
